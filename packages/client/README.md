# @tscomfy/client

[![npm](https://img.shields.io/npm/v/@tscomfy/client)](https://www.npmjs.com/package/@tscomfy/client)

Runs tscomfy workflows on a ComfyUI server. It queues a workflow, streams progress, live
previews and outputs, and tells you how the job ended. It uses only `fetch` and `WebSocket`, with
no runtime dependencies, and runs on Node 24+, Bun 1.4+, Deno and browsers.

```sh
npm install @tscomfy/client @tscomfy/core
```

```ts
import { workflow } from "@tscomfy/core";
import { connect, fetchFile, outputFiles, submit } from "@tscomfy/client";
import { local } from "./comfy/local/index.ts"; // generated by `tscomfy generate`

const wf = workflow(local, ({ n }) => {
  const [model, clip, vae] = n.CheckpointLoaderSimple({ ckpt_name: "sdxl.safetensors" });
  const latent = n.KSampler({
    model,
    positive: n.CLIPTextEncode({ clip, text: "a lighthouse at dusk" }),
    negative: n.CLIPTextEncode({ clip, text: "" }),
    latent_image: n.EmptyLatentImage({ width: 1024, height: 1024 }),
    seed: 42n,
    sampler_name: "euler",
    scheduler: "normal",
  });
  const save = n.SaveImage({ images: n.VAEDecode({ samples: latent, vae }) });
  return { save }; // kept as wf.handles
});

const comfy = await connect({ url: "http://127.0.0.1:8188" });
const job = submit(comfy, wf, { previews: "taesd" });
for await (const event of job.events) {
  if (event.type === "progress") console.log(`${event.node}: ${event.value}/${event.max}`);
  if (event.type === "preview") showPreview(event.mime, event.bytes);
}
const outcome = await job.outcome;
if (outcome.status === "success") {
  for (const file of outputFiles(outcome, wf.handles.save)) {
    const { bytes } = await fetchFile(comfy, file);
    // write bytes to disk, show them, upload them…
  }
}
await comfy.close();
```

**Reliable by design.**
- **No missed events.** The client chooses the prompt id and subscribes before it queues.
- **The server's record decides.** The outcome comes from the server's record of the job, so a
  dropped websocket costs a moment of progress, never a wrong or missing result.
- **Outcomes are data.** The outcome is `success`, `rejected` (the server's validation errors as
  diagnostics), `failed` (the node's error) or `cancelled`.
- **What rejects.** The outcome promise rejects only when you abort (`signal`) or the server
  can't be reached (`ClientError`).
- **Exact seeds.** Seeds beyond 2⁵³ arrive exactly as written.

**Also:** `job.cancel()`, `uploadFile` for loader inputs, `fileUrl` for `<img src>`, and
`outputOf(outcome, node)` for a node's text output.

## Requirements

- **Servers:** ComfyUI 0.26 or later.
- **TypeScript:** your project needs a runtime's web types (`@types/node`, Bun's types, Deno, or
  the DOM lib). The package's declarations name `fetch`, `WebSocket` and `AbortSignal`.
- **Browsers:** a page needs the server's permission. Start ComfyUI with
  `--enable-cors-header <origin>`, or serve the page from the same origin.
